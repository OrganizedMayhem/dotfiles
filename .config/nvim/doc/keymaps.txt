*keymaps.txt*  Personal keymap reference                        *my-keymaps*

Leader and localleader are both <Space>.  Press <Space> and wait for
which-key to show the next keys, or <Space>? for every mapping.

Mode column:  n normal   x visual   o operator-pending   i insert
              t terminal   "LSP" = only in buffers with a language server

                                        Type |gO| for a table of contents.

5. Treesitter text objects and motions            *my-keymaps-textobjects*

Text objects (x, o) - "a" is outer, "i" is inner:

  af  if          function
  ac  ic          class
  aa  ia          parameter / argument
  al  il          loop
  ad  id          conditional
  ae  ie          comment
  an  in          parent / child syntax node               (built-in)

Built-in ap/ip (paragraph), as/is (sentence) and ab/ib (block) are
untouched.

Motions (n, x, o):

  ]m  /  [m       Next / prev function start
  ]M  /  [M       Next / prev function end
  ]n  /  [n       Select next / prev node (x only)         (built-in)
  ]N  /  [N       Select next / prev sibling (x only)      (built-in)

Swaps (n):

  <Space>a        Swap parameter with next
  <Space>A        Swap parameter with previous

8. Completion (blink.cmp, insert mode)             *my-keymaps-completion*

  <C-Space>       Show menu / toggle documentation
  <C-y>           Accept selected item
  <C-e>           Cancel
  <C-n>  /  <C-p> Next / prev item  (also <Down> / <Up>)
  <C-b>           Scroll documentation up
  <C-k>           Toggle signature help
  <Tab> / <S-Tab> Jump to next / prev snippet placeholder

<C-f> is unmapped on purpose, so it keeps its default behaviour.

9. Oil (inside an Oil buffer)                           *my-keymaps-oil*

  <CR>            Open entry
  <C-s>           Open in vertical split
  <C-h>           Open in horizontal split
  <C-t>           Open in new tab
  <C-p>           Preview
  <C-c>           Close
  <C-l>           Refresh
  -               Parent directory
  _               Open current working directory
  `  /  ~         :cd / :tcd to this directory
  gs              Change sort order
  gx              Open with system handler
  g.              Toggle hidden files
  g\              Toggle trash view
  g?              Show help

10. Obsidian (markdown notes in a vault)                *my-keymaps-obsidian*

  <CR>            n   Smart action: follow link, toggle checkbox, etc.
  ]o  /  [o       n   Next / prev link in note

Inside the Obsidian picker:

  <C-x>           New note from query / tag the note
  <C-l>           Insert link / insert tag

Command: `:ObsidianOptionsTrade` creates an options-trade note from prompts.
